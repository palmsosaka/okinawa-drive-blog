**結論: 美ら海水族館の「黒潮の海」バックヤードツアー(30分・1人2,000円)は、遅刻10分でキャンセル料100%。那覇空港からレンタカーで行くなら、ツアー開始の約3時間前には空港を出る計画が安全です。** 予約は30日前の午前10時から。日程が決まったら先に枠を押さえるのが得です。

## バックヤードツアーの概要(結論: 1組最大5名の貸切)

**ガイドを貸し切って、大水槽の上の橋から生き物を間近で見られるのが特徴です。** 公式サイトの案内では、2026年7月1日(水)から「当面の間」開催されています。

| 項目 | 内容 |
|---|---|
| 所要時間 | 30分 |
| 料金 | 1人2,000円(別途入館料が必要) |
| 定員 | 各回1組限定(最大5名) |
| 開催時間 | 10:00 / 11:00 / 12:00 / 12:30 / 13:00 開始(各30分) |
| 予約 | オンライン事前購入。実施日の30日前・午前10時から販売 |
| 対象 | 小学生以上を推奨(小学生以下は保護者同伴) |

※料金・時間・運用は変更されることがあります。必ず公式サイトで最新情報を確認してください。

## 参加条件の注意点(結論: ベビーカー不可・遅刻不可)

**小さなお子様連れは、ベビーカー・抱っこ紐で参加できない点に注意が必要です。** 公式案内の主な条件は次のとおりです。

- 30分間、自力で歩けること
- 車椅子・ベビーカー・抱っこ紐での参加は不可
- 滑りにくい靴(スニーカー等)が必須
- 大きな荷物は持ち込み不可
- 開始時間より10分以上遅れるとキャンセル扱い(キャンセル料100%)

**大きな荷物は車内に置いて入れる**のも、レンタカー利用の地味なメリットです。ただし、車内に貴重品を置いたままにしないでください。

## 那覇空港からの逆算スケジュール(結論: 午後の便が現実的)

**飛行機で到着する日にツアーへ行くなら、12:30〜13:00開始の回が現実的です。** 空港到着後の営業所での手続きに30〜60分、那覇空港から名護方面へは沖縄自動車道経由でおおむね2時間前後が目安です。

| 到着後の流れ | 所要時間の目安 |
|---|---|
| 到着ロビー → 営業所(送迎車の場合。会社により異なる) | 約20〜30分 |
| 貸出手続き | 約30〜60分 |
| 那覇IC → 許田IC → 本部方面 | 約2時間前後 |
| 駐車場 → 入館 → 集合 | 約20〜30分 |

たとえば12:30開始の回なら、**遅くとも9:30ごろに空港を出る**イメージです。繁忙期は許田IC以北が混むため、さらに余裕を見てください。到着便が午前遅めなら、前泊・那覇市内からの出発も検討する価値があります。

**結論: 親会社が約173億円の最終赤字でも、ジャングリア沖縄は「運営を継続する」と説明されており、レンタカー旅行の計画は通常どおり立てられます。** 気になるのは経営ではなく、出発前の営業情報の最新確認です。

## 何が報じられたのか(結論: 初決算で約173億円の赤字)

**ジャングリア沖縄を運営する会社の親会社、ジャパンエンターテイメントホールディングスの2026年6月期決算は、約173億円の最終赤字でした。** 時事通信・沖縄タイムスの報道をもとに整理します。

| 項目 | 報じられた内容 |
|---|---|
| 親会社の最終損益(2026年6月期) | 約173億円の赤字 |
| 子会社(運営会社)の最終損益 | 約89億円の赤字 |
| 想定来場者数(開業〜1年) | 150万人 |
| 実績(延べ) | 約100万人(1日平均 約2,700人) |
| 赤字の主因 | 子会社株式の評価損の計上など |

数値は報道時点のものです。詳細は各社の報道と会社発表で最新を確認してください。

## 旅行者への影響(結論: 運営継続の方針)

**報道では、経営陣が「顧客へのサービス提供や各種契約・取引に影響はなく、今後も運営を継続する」とコメントしたとされています。** 株主総会では経営陣がお詫びを述べ、新たなスポンサー探しにも言及したと伝えられています。営業日や料金が今後変わる可能性はゼロではないため、訪問前の公式サイト確認をおすすめします。

## レンタカー計画のポイント(結論: 平日は狙い目、ただし要確認)

**来場者が想定を下回ったことから、平日は待ち時間が短い可能性があります。** ただし2027年1月から月曜定休になるなど営業体制の変更もあるため、日程は必ず公式で確認してください。

| 項目 | 目安 |
|---|---|
| 那覇空港 → 那覇IC | 約20分(営業所での手続きは別途30〜60分) |
| 那覇IC → 許田IC | 約60分 |
| 許田IC → ジャングリア | 約15〜25分 |
| 合計 | 約90〜110分 |

北部は古宇利島や名護方面の立ち寄りもしやすく、帰りに1〜2スポット足せるのがレンタカーの利点です。アクセスの詳細は[ジャングリア沖縄へレンタカーで行く完全ガイド](/blog/junglia-okinawa-rentacar-access/)、待ち時間の変化は[開業1周年の記事](/blog/junglia-1shunen-tornado-rentacar/)、営業日の変更は[月曜定休の記事](/blog/junglia-getsuyou-kyugyo-rentacar/)もあわせてどうぞ。

**結論: 那覇空港の忘れ物は、2026年11月10日(火)から電話だけでなくチャットでも問い合わせできるようになります。** 那覇空港ビルディングが「落とし物クラウドfind」を導入するもので、24時間受付・4言語対応です。レンタカーで空港へ戻る旅行者も、窓口の使い分けを知っておくと慌てずに済みます。

## 何が変わる?(結論: 電話のみ→チャットが追加)

**メール認証だけでブラウザからチャットを始められ、アプリのインストールは不要です。** 那覇空港では月間約2,000件の忘れ物の問い合わせに対応しており、これまで電話のみだった窓口がチャットに広がります。

| 項目 | 内容 |
|---|---|
| 利用開始日 | 2026年11月10日(火) |
| 対象 | ターミナルビル内で拾得され、インフォメーションカウンターで預かった忘れ物 |
| 入口 | 那覇空港公式サイト「落し物・忘れ物のお問い合わせ」ページ |
| 対応言語 | 日本語・英語・中国語(簡体字)・韓国語 |
| 受付時間 | 24時間 |
| オペレーター対応 | 9:00〜22:00(21:00以降の新規は翌朝9:00以降に順次回答) |

## 「横断検索」で複数施設をまとめて照会

**交通事業者や商業施設の忘れ物をまとめて照会できる「横断検索」にも参加します。** 持ち主がチャットで候補施設を選ぶと、オペレーターが検索して回答する流れです。料金については発表資料に記載がなく、不明です。

## レンタカー利用者は窓口を間違えないで(結論: 車内の物は借りた店舗へ)

**今回の対象はターミナルビル内の忘れ物で、レンタカー車内の忘れ物は含まれません。** 那覇空港周辺や豊見城の営業所に返却したあとで車内に置き忘れに気づいた場合は、借りたレンタカー会社へ直接連絡してください。

- ターミナル内(搭乗口付近・売店・カウンター) → 空港のチャット/電話
- レンタカー車内 → 借りた店舗へ電話

連絡先を取り違えると、見つかるまでの時間が無駄になります。レンタカー車内の対処手順は[沖縄レンタカーの忘れ物、連絡〜返送まで4ステップで解説](/blog/okinawa-rentacar-wasuremono-taiou/)にまとめています。

## まとめ

- 11月10日(火)から那覇空港の忘れ物問い合わせにチャットが加わる
- 24時間受付・4言語対応、オペレーター対応は9:00〜22:00
- レンタカー車内の忘れ物は対象外。借りた店舗へ連絡

内容は変更されることがあります。利用前に那覇空港の公式サイトで最新情報を確認してください。

返却前は、座席下・ドアポケット・ドリンクホルダー・トランクの4カ所を確認してから那覇空港へ向かいましょう。

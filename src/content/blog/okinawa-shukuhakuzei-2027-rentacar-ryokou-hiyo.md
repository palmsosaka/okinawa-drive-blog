**結論: 沖縄の宿泊税は2027年2月1日開始予定で、1人1泊の宿泊料金の2%(上限2,000円)が基本です。** 素泊まり8,500円の宿なら税額は160円。家族4人2泊でも2,000円前後なので、旅行予算への影響は小さく、レンタカー代と同じ感覚で「先に見積もりに入れておく」だけで足ります。

※制度の内容や開始時期は変更されることがあります。必ず沖縄県の公式サイトで最新情報をご確認ください。

## 宿泊税の基本(結論: 宿泊料金の2%、上限は1人1泊2,000円)

**税額は「1人1泊の素泊まり料金(1,000円未満切り捨て)×2%」で、上限は2,000円です。** 県の公式ページに記載されている主な内容は次のとおりです。

| 項目 | 内容 |
|---|---|
| 施行予定日 | 2027年(令和9年)2月1日 |
| 税率 | 定率2%(上限2,000円) |
| 課税標準 | 1人1泊の宿泊料金。1,000円未満切り捨て、上限100,000円 |
| 市町村も課税する場合 | 県0.8%(上限800円)+市町村1.2%(上限1,200円) |
| 対象施設 | ホテル・旅館・簡易宿所、特区民泊、住宅宿泊事業法の民泊 |
| 免除 | 学校教育活動での宿泊(大学を除く)、規定の大会参加時など(証明書が必要) |
| 支払い方法 | 宿泊施設が宿泊者から預かり、県へ納入 |

市町村分を併せて課税する地域では、県と市町村の合計が2%になる設計です。県の案内では、本部町・恩納村・北谷町・宮古島市・石垣市・名護市の施設は市町村ごとの手続きになるとされています。美ら海水族館やジャングリア沖縄がある北部方面に泊まる場合は、宿泊先に事前確認すると安心です。

## いくらになる?宿泊タイプ別の目安(結論: 1泊100〜400円が中心)

**1人1泊あたりの税額は、素泊まり5,000円で100円、12,000円で240円、20,000円で400円です。** 計算は県の例(8,500円→課税標準8,000円→160円)と同じ方式です。

| 1人1泊の素泊まり料金 | 課税標準 | 税額(2%) |
|---|---|---|
| 5,000円 | 5,000円 | 100円 |
| 8,500円 | 8,000円 | 160円 |
| 12,000円 | 12,000円 | 240円 |
| 20,000円 | 20,000円 | 400円 |
| 100,000円以上 | 100,000円 | 2,000円(上限) |

## レンタカー旅行の予算への影響(結論: 4人2泊で2,000円前後)

**家族4人で2泊する場合、1人1泊12,000円の宿なら延べ8泊分で1,920円です。** 1人あたり約480円で、那覇空港でのレンタカー貸出手続き(30〜60分)の間に確認できる程度の金額感です。

- 宿泊税はレンタカー料金とは別枠(宿泊施設で案内される)
- 予算表には「宿泊費+宿泊税(宿泊費の約2%)」と書いておくと見積もりの抜けを防げる
- 割り勘の場合は、宿泊税も宿泊費に含めて均等に分けるとシンプル(精算の考え方は[沖縄レンタカー代、友人4人での割り勘目安と精算法](/blog/okinawa-rentacar-warikan-seisan/)も参考に)

## 事業者側の準備はまだ途上(結論: 直前に案内が変わる可能性あり)

**沖縄タイムスの見出し(2026年11月7日配信)では、宿泊税の事業者登録は全体の約2割にとどまり、県が月内の申請を呼びかけていると報じられています。**詳細は同紙の記事で確認してください。 開始が近づくと、宿泊施設ごとに表示方法(税込・税別)や徴収方法の案内が変わる可能性があります。予約時の総額表示を確認し、不明点は予約先に問い合わせるのが確実です。

## 旅行前チェックリスト

1. 2027年2月1日以降の宿泊かどうかを確認(以前の宿泊は対象外の見込みですが、最新は公式サイトで確認)
2. 宿泊先が市町村税を併課する地域か(名護・本部・恩納・北谷など)を確認
3. 予約サイトの総額に宿泊税が含まれるかを確認
4. レンタカーは宿泊日程に合わせて早めに予約(那覇空港発着の場合、繁忙期は特に早めが安心)

宿泊日程が決まったら、那覇空港発着のレンタカー見積もりもあわせて確認すると、旅費の全体像が早くつかめます。ご不明な点は当社の予約窓口からもご相談いただけます。
